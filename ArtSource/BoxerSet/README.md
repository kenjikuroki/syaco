# Boxer set
User reference: reference.png.
Blender source: Boxer_Set.blend. Exchange formats: Boxer_Set.fbx, Boxer_Set.glb.
Previews: preview.png, front.png, side.png. Regenerate with create_boxer.py in Blender 5.2.
Six replacement meshes share the D character rig: headband/head, left glove, right glove, segmented trunks/abdomen, tricolor tail and six sneakers/legs.
Six simple materials and UVs. 29,871 imported Unity triangles; all vertices weighted.
Customize > Boxer opens individual toggles and full set. Equipment saves automatically. Robot and boxer pieces may be mixed across slots; equipping one replaces the other in that slot. Head variants hide the crown. This prototype set is free to equip; no purchase flow added.
Verified slot mapping, bone mapping, punch mesh deformation, both orientations, mixed robot/boxer configuration and removal restoring original meshes. iOS device performance is unmeasured.
