# Robot armor set
Reference: reference.png supplied by user.
Files: Robot_Set.blend, Robot_Set.fbx, Robot_Set.glb; preview.png, side.png, front.png.
Run create_robot.py in Blender 5.2 to regenerate from ../D_Character/D_Mantis_Game.blend.
Six skinned modules share the existing game skeleton and underhand punch animation. This is an equipment variant of the established D character, not a replacement combat rig.
Six simple materials, UVs packed per module; cyan elements use emission. No texture dependency.
Unity entry: Customize > Robot armor. Full set and per-part toggles; automatic save.
Standalone performance and physical iOS rendering require device profiling before release.
