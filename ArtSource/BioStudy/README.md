# Biological mantis shrimp study — preview only

Editable source: Mantis_BioStudy.blend. Rebuild with Blender --background --python create_bio_study.py. Four Cycles renders: three-quarter, side, front, face detail.

This is a static design study derived from the natural-proportion A6 construction, with separately editable pieces, subdivision/bevels, procedural chitin materials, a corneal middle-band interpretation, articulated feeding appendages and finer walking-leg detail. It is not an anatomical reconstruction. Generated surface patterns are artistic approximations, not scanned skin or a literal ommatidial layout.

No files in Assets, game prefabs, scenes or builds are changed. This study has no newly validated gameplay rig, no baked mobile material atlas, and no mobile geometry budget optimization. The procedural Blender materials must be baked or translated before Unity use. The existing game model remains intact.

Visual reference:
- Monterey Bay Aquarium, Peacock mantis shrimp: https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/peacock-mantis-shrimp
- Natural History Museum, Mantis shrimp: https://www.nhm.ac.uk/discover/mantis-shrimps.html

Views were inspected after rendering. Shape and material changes should be reviewed before game integration.
